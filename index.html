01 / 关于我

一边学着做个合格的 学生，
一边偷偷研究怎么让机器听话

我叫 天逸。名字里的“逸”取的是“逃逸”的意思——逃出按部就班的剧本，去试试那些没人替我安排好的事。 编程对我来说就是这样的出口：它不看你出身，只看你想清楚没有。

现在我在 沈阳理工大学 读 计算机科学与技术， 主要自学 Python，同时喜欢把学到的东西做成看得见的小网页。 我最享受的时刻不是“写完了”，而是“报错了，但我知道为什么”。

课堂之外，我是个标准的二次元，如果只能选一个最爱的名字，那一定是 洛天依。 我反复写过她的设定，也把那份审美搬进了这一页：宝蓝、冰蓝、白蕾丝，还有一整片星空。 我着迷的从来不是热闹，而是有人愿意认真把一件小事做到发光。

另一个能让我安静下来的爱好是下棋。落子之前先算清后面几步，输过很多次才明白： 急着吃子的人往往先输。这个习惯后来直接变成了我写代码的方式——先想清楚结构，再动手敲第一行。

还有一件我很坦荡的事：我喜欢女装。一开始只是觉得裙子好看，后来开始认真研究版型、 配色和蕾丝的走向——这件事和写代码其实很像，都是把脑子里的样子一点点做出来。 好看的东西不该分性别，穿得开心就是最好的理由。

剩下时间基本交给游戏了。我偏爱那种能慢慢想清楚的策略类，一局能琢磨一晚上， 反复推演"如果当时换一步会怎样"。玩到某个节点我突然想：既然这么在意它好不好玩， 那不如自己试着做一个。——这一页就是那个念头的第一个产物。

04 / 星轨

一路留下的 脚印

  1. 更早之前

    先爱上了洛天依

    在接触代码之前，先被那个蓝白色的身影和"把虚拟唱成真的"这件事吸引。后来我才发现，做编程其实是同一件事：让想象里的东西真的存在。

  2. 埋下种子

    在游戏里第一次想"它到底怎么做出来的"

    打策略游戏打久了，开始不满足于"玩得好"，而是好奇规则背后是怎么被设计出来的。那个好奇一直放着，直到后来变成"要不我自己写一个"。

  3. 起点

    第一次让程序替我做事

    写下第一段 Python，看着终端里跳出结果，第一次觉得"原来我也能让机器听我的话"。

  4. 第一次完整项目

    猜数字小游戏上线 GitHub

    从"能跑"到"别人 clone 下来也能跑"，学会了整理文件和写 README。

  5. 转折点

    做了一版很简陋的个人主页

    那时候只有几个页面和一段能提交的留言表单，样式几乎是空的。它不好看，但它是我第一次把想法放上互联网。

  6. 现在

    推翻重做，于是有了这座星庭

    重新设计视觉、重写结构、补上动效与响应式，并用 GitHub Pages 部署到互联网上——也就是你正在看的这一页。

  7. 下一步

    把好奇心继续往下挖

    深入 JavaScript、接触后端与数据，试着做一个真的有别人在用的东西。

    06 / 角色

    天逸，也有一份 角色设定

    我自己创作了这个 AI 形象，也是这一页的视觉来源。她不是我，但她替我把那些不太好意思直说的话说了出来。

    AI 形象

    天逸 · 王室少女

    宝蓝丝绒 × 白蕾丝 狮子座 INTP

    “规矩是死的，人是活的，那么守规矩有意思吗？”

    她的设定是融合了洛天依特征的王室少女：偏爱宝蓝色丝绒与浅蓝缎面拼接的复古长裙， 常戴镶嵌白色羽毛的钻石小冠和珍珠项圈。看起来很端庄，实际上会偷偷溜出宫去市集蹲在手艺人旁边看一下午捏糖人。

    顺便说一句，我是洛天依的死忠粉——这套配色、这条长裙、这片星空，都是这份偏爱长出来的样子。

    我把她放在这一页的最中间，因为她的性格其实是我的理想型： 嘴上毒舌、心里柔软，不端架子，比起按部就班更在意真实的好奇心。

    典型经历

    溜出王宫混进市集，嘴上嫌弃街边小吃不登大雅之堂，兜里却揣着半块没吃完的桂花糖。

    内在冲突

    既放不下王室的骄傲，又抗拒被身份约束，最后总是好奇心赢，把规矩抛在脑后。

    核心执念

    厌倦循规蹈矩的沉闷，最向往宫外鲜活的烟火气——比起整齐的礼仪，更在意那些能让人停下脚步的细节。

    名字的来历

    “逸”取“逃逸”之意：逃出被安排好的剧本，去做那些没人替你决定的事。

    审美的来源

    洛天依的死忠粉。她身上的蓝与白、还有那种站在星空里的安静感，直接长成了这一页的配色。
