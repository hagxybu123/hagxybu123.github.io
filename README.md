# 天逸 · 星庭 | Tianyi · Star Court

> 在代码里，给自己造一座王宫。

一个纯手写的静态个人主页：深空星云视觉、滚动叙事、响应式布局、亮暗主题切换、
Canvas 星野与流星，以及一个能立刻使用的留言板。**零依赖、零构建**，
克隆下来直接打开 `index.html` 就能看。

## 这是什么

这是对早期那版"成神之路"小网站的**完全重做**。

第一版只有几个页面和一段能提交的表单，样式几乎是空的，连 `style.css` 都是 0 字节。
这一版重新设计了整套视觉与信息结构，并把设计语言和自己定义的形象对齐：
宝蓝丝绒、冰蓝绸面、白色蕾丝与星光金。

## 技术说明

| 项目 | 做法 |
| --- | --- |
| 结构 | 单页 + 锚点导航，语义化 HTML |
| 样式 | 原生 CSS：设计变量、`clamp()` 流式排版、`backdrop-filter` 玻璃拟态、容器自适应网格 |
| 脚本 | 原生 JavaScript，无任何框架或 CDN 依赖 |
| 星空 | Canvas 2D 绘制星野与流星，带滚动视差 |
| 动效 | `IntersectionObserver` 控制入场、技能条与数字滚动，尊重 `prefers-reduced-motion` |
| 留言板 | 浏览器 `localStorage` 持久化，纯前端实现 |
| 主题 | `data-theme` + CSS 变量，偏好写入 `localStorage` |
| 字体 | 系统字体栈，不加载外部字体，首屏无字体闪烁 |

## 本地预览


## 视觉效果

- **星野系统**：星点（最多 260 颗，约 1/5 为金色，亮星带十字星芒）、彗星（平均 1.6~3.2 秒一颗，约 40% 为金色）、上浮星尘、呼吸星云
- **交互**：鼠标靠近会点亮星点；点击页面任意位置爆开金色星光
- **漂浮光点层**：12 个纯 CSS 光点持续上浮
- **性能**：标签页切后台时暂停动画循环；`prefers-reduced-motion` 下只绘制静态一帧
